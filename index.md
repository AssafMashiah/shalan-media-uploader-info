# Shalan Media Uploads

Shalan Media Uploads is a private, owner-operated automation tool for uploading videos into an approved Google Drive media folder. It is operated by Assaf Mashiah for his own projects.

The tool requests Google's `drive.file` permission: access to files it creates or that the account owner specifically authorizes for this application. It does not request access to all Drive files, Gmail, Calendar, or contacts.

The intended upload workflow creates private video files, verifies their size and checksum, and returns a Drive link. It does not automatically publish videos, change sharing permissions, overwrite existing videos, or delete local originals. Upload access is subject to the owner's configured project/folder allowlist.

This site contains information only. It does not accept uploads, run Google login, or host videos or account credentials.
